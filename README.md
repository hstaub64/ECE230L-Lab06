## Lab Questions

### 1 - How might you add more than two bits together?

  * Adding more instances of the full adder and bringing the carry from the previous adder will allow more than two bits to be added together.

### 2 - What is the importance of the XOR gate in an adder?

  * The XOR gate is important because it can be used to represent the addition of bits. If the OR gate was used instead, when both bits are 1, the result would be wrong, since it would be 1 instead of 0 with a cary over of 1.

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?

  * The largest number the two bit adder can add is seven, represented as 11 with a carry of 1. Anything over seven would not be able to be represented with the adder since, like the example of the single adder, we wont be able to keep track of the carry in the 8th position.
